# aldeareneyao.github.io

Personal website of Rene Yao Aldea — served by GitHub Pages.

- `v1` (2016): Bootstrap 3 + jQuery.
- `v2` (2026): "Noir Spotlight" redesign — plain HTML, CSS and a few lines of vanilla JS.

## Principles

- No trackers, analytics or third-party requests. Fonts are self-hosted in `fonts/`.
- No build step: edit `index.html`, `css/style.css`, `js/main.js` and push.

## Preview locally

```bash
python3 -m http.server 8000
```

Fonts: Anton, JetBrains Mono and Newsreader — SIL Open Font License 1.1.
